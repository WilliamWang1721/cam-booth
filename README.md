# Cam Booth

macOS 原生拍照 / 录像软件，定位是 Photo Booth 的平替：打开即用，高级功能默认收起。

## 设计原则
- **最小必要**：只做拍照、录像、选摄像头；其余收进"高级设置"。
- **高性能靠系统，不靠自己搬帧**：采集、预览、硬件编码（H.264/HEVC）全部交给 AVFoundation / VideoToolbox，帧数据不经过我们的代码。
- **Rust 核心保持很小**：只放不依赖系统的纯逻辑（文件命名、时长格式化），无第三方依赖，C ABI 暴露给 Swift。
- **系统原生**：SwiftUI + 系统组件；MacBook 摄像头的人像 / 居中前台 / 影棚光 / 桌上视角由系统提供，App 里一键打开系统面板。

## 结构
- `core/`：Rust 核心（`cargo test` 可在 Linux 上跑）。
- `app/`：SwiftUI 应用，工程由 XcodeGen 从 `app/project.yml` 生成（不提交 `.xcodeproj`）。
- `.github/workflows/ci.yml`：Linux 上测核心；macOS runner 上编译通用二进制 App 并产出 `CamBooth.zip`。**本机 Mac 不参与构建。**

## 当前功能（v0.1.0）
照片 / 视频切换、空格快门、摄像头选择（内置、外接、iPhone 连续互通）、720p/1080p/4K（按设备支持）、HEVC、录制计时。

- **镜像**：操作栏上一键切换，预览与存盘的 JPEG/MOV 同时镜像（在采集连接上生效，不是只翻屏幕）。
- **保存位置**：默认直接写入 `~/Downloads`，不再自建目录；高级设置里可选任意文件夹（记在 UserDefaults，目录失联自动回落到 Downloads）。
- **倒计时**：关 / 3 / 5 / 10 秒可选，拍照和录像都生效；预览上大号倒数，每秒一声提示音、快门一声长音（内存合成 WAV，不打包音频资源）。空格可在倒数中取消。
- **影像栏**：操作栏上方一条 Photo Booth 式横栏，显示本次会话拍摄的全部画面（视频带时长角标）；按住拖出窗口即可分享到其他 App，右键可打开 / 在访达中显示 / 移到废纸篓。
- **方向修复**：导出视频上下颠倒已修 —— 采集连接的 `videoOrientation` 强制 `landscapeRight`，预览、相片、录像三者一致（此前预览层单独旋转，画面看起来对、文件却是倒的）。
- **相机自动休眠**：高级设置里可选无操作 1 / 2 / 5 分钟后自动停掉摄像头采集以省电；点击画面或快门随时唤醒，录像中不休眠。
- **导出格式**：高级设置里可选 MOV（默认，硬件直录）、MP4、HEVC、M4V；非 MOV 格式在录完后用系统 `avconvert` 转码，文件名后缀随之变化。
- **麦克风**：高级设置里可选择输入设备、拖动调节输入电平（CoreAudio 硬件音量，设备不支持时自动隐藏滑条并提示走系统设置）。
- **快捷分享**：影像栏右键「分享…」或操作栏分享按钮，一键打开系统分享面板（邮件、信息、AirDrop、微信等第三方入口自动出现）。

旧版自建的 `~/Pictures/Cam Booth`、`~/Movies/Cam Booth` 已不再使用；里面已有的文件保持原样，需要的话自行清理。
